## ✨ Features

- **💊 Pill-Shaped Search Bar**:
  - Instant live filtering of all installed applications as you type.
  - Press `Enter` to quickly launch the first matching application.
  - Real-time matching counter badge and one-click clear button (`x`).
  - Press `Esc` to clear search and dismiss focus.

- **🎡 6-App Carousel Dock**:
  - Displays exactly **6 circular application slots** at a time on screen.
  - Smooth `<` and `>` navigation arrows to browse through your installed apps.
  - Mouse wheel support: scroll up/down anywhere on the dock to smoothly page through apps.
  - Interactive hover effects: spring zoom animation, KDE accent border glow, and floating app name tooltips.

- **🎨 Modern Glassmorphism Aesthetic**:
  - Translucent frosted glass backgrounds that blend seamlessly with any wallpaper and dark/light KDE themes.
  - Designed specifically for KDE Plasma Desktop.

- **⚙️ Fully Configurable**:
  - Right-click widget -> **Configure Widget...** to adjust:
    - Navigation step (1 app at a time or full page of 6 apps).
    - Loop around (infinite carousel).
    - Show/hide application name tooltips.
    - Icon circle size (40px - 68px).

## 📥 Installation

Anyone can install this widget with a single command after cloning:

```bash
git clone https://github.com/PeniaCrysinne/capsule-launcher.git
cd capsule-launcher
./install.sh
```

The script will automatically register the plasmoid with `kpackagetool6` and refresh your KDE Plasma environment.

---

## 🖥️ How to Add to Your Desktop

1. **Right-click** on any empty space on your KDE Desktop.
2. Select **"Add Widgets..."**.
3. In the widget browser, search for **"Capsule Launcher"**.
4. Drag and drop it onto your desktop!

---

## 🗑️ Uninstallation

If you ever wish to remove the widget, simply run:

```bash
cd capsule-launcher
./uninstall.sh
```
